# Raya

> Raya (Raya App Inc) is a private, membership-based global community for dating, friendship, and professional networking. Founded by Daniel Gendelman in 2014 and launched in February 2015 out of Los Angeles, California. Membership is application-only, reviewed on an ongoing basis by a global committee; accepted members choose a 1, 6, or 12 month paid subscription. The product is iOS-only.

Raya is a consumer application company, not an API provider. As of 2026-08-02 there is no public developer program: no developer portal, no API documentation, no OpenAPI/GraphQL/AsyncAPI contract, no SDKs, no CLI, no MCP server, no webhooks, and no A2A agent card. `api.rayatheapp.com` is a private first-party mobile backend that returns a JSON 404 for every unauthenticated path. Do not attempt to integrate with it; there is no published, supported interface.

## Notes

- The web hosts (rayatheapp.com, www.rayatheapp.com, raya.co) serve a client-rendered React SPA that answers HTTP 200 with the same HTML shell for every path. Treat any 200 from those hosts for `/openapi.json`, `/llms.txt`, or `/.well-known/*` as a false positive.
